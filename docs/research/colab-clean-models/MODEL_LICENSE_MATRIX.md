## Gate before model execution

No model download or load until the exact repository commit/revision, artifact filename, byte size, SHA-256, source, license text, and base/dependency chain are recorded. Prefer `safetensors` where the project offers it. A hash proves identity, not provenance or rights. Any unresolved license or unsafe serialization is a stop condition, not a prompt to use a mirror.
