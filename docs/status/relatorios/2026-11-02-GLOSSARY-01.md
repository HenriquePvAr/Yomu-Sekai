## Resumo

Implementação completa do glossário de nomes por série. O usuário pode definir
substituições de nomes (ex.: `Sunless = Sunny`) diretamente na UI; os pares são
persistidos por série (chave derivada da URL) e aplicados como pós-processamento
em todos os tradutores.

## Fluxo de dados

```
UI textarea
  → nameGlossaryPairs() → payload name_glossary
  → UiBridge._name_glossary() → job config
  → job_runner → YOMU_NAME_GLOSSARY (JSON env var)
  → benchmark_pipeline → translator.set_name_overrides()
  → translate_many() → _apply_name_overrides() (pós-tradução)
```

## Notas de design

- Substituição como pós-processamento (não pré-processamento) para não confundir a
  detecção de contexto do tradutor
- Para DeepL: nomes de origem também registrados em `_protected_names` para garantir
  passagem verbatim antes da substituição
- Limite de 50 pares por série na UI e no bridge
- Regex com word-boundary (`(?<![A-Za-z0-9_-])..(?![A-Za-z0-9_-])`), case-insensitive
